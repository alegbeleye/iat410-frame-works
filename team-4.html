Iterative Design: Refinements and Prioritization

2026-02-07 - 09:00

From playtest data I prioritized nondisruptive, clarity-focused changes: highlight the gas station and safehouse on the minimap for the first five seconds of each run to orient players; implement a multi-stage fuel warning (amber at 30%, flashing red and audio cue at 15%); add a concise audiovisual cue and tiny particle burst when a flyer is distributed; and move reset into the pause menu to avoid accidental restarts. Each change was implemented behind a feature flag so it can be A/B tested. I updated the GDD with explicit tuning numbers and implementation notes so future team members can adjust values without altering core code.
